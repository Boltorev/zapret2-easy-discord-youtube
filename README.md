# Запрет2 Easy

Удобная оболочка для **zapret2** (DPI-bypass для Windows): меню на русском,
готовые пресеты, служба Windows с автозапуском и автоматическая смена стратегий
(AUTO). Запустил батник — выбрал пункт — работает в фоне.

Движок — [zapret2](https://github.com/bol-van/zapret2) от **bol-van**, взят как есть,
без изменений. Оболочка, пресеты в синтаксисе nfqws2 и оркестратор AUTO — отдельная
работа. Проект **не является** официальным проектом bol-van или Flowseal.

> Не знаете, что такое DPI? И не нужно. DPI — оборудование провайдера, которое решает,
> какие сайты вам открывать. Программа пытается его обмануть.

---

## Три шага для новичка

**1. Скачайте релиз.**
Возьмите `zapret2-easy-<версия>.zip` со страницы **Releases** этого репозитория
и распакуйте.

**2. Распакуйте в `C:\zapret2-easy`.**
Именно такой путь: без кириллицы и пробелов (служба Windows капризна к ним),
не внутри OneDrive и не на рабочем столе. Если положите в другое место, установщик
предупредит и предложит перенести.

**3. Запустите `service.bat` от имени администратора.**
Правый клик → «Запуск от имени администратора». В меню выберите **«1. Установить»**
и пресет **AUTO** (он предлагается по умолчанию).

Готово: служба запущена, автозапуск включён, окно можно закрыть.

## Что внутри меню

| Пункт | Что делает |
|---|---|
| 1. Установить | выбрать пресет и поставить службу |
| 2. Удалить | остановить и удалить службу, завершить процесс, при желании снять драйвер |
| 3. Статус | состояние службы, процесса, пресета, фильтров |
| 4. Сменить пресет | переустановить службу с другим пресетом |
| 5. Тесты пресетов | прогон пресетов и замер нагрузки на CPU |
| 6. Диагностика | права, путь, драйвер, BFE, прокси, конфликтующее ПО, осиротевшие процессы |
| 7. Списки и исключения | ваши домены и IP, папка `lists` |
| 8. Game Filter | игровые порты |
| 9. IPSet Filter | включить/выключить список из 33k записей |
| 10. Обновить списки | скачать список по кнопке, с бэкапом и проверкой |
| 11. Проверить обновления | запрос к GitHub, ничего не скачивает |
| 12. Выход | |

Всё меню на PowerShell (`core\Menu.ps1`), `service.bat` — только тонкий лаунчер.

## Честные ограничения

Это важно прочитать, чтобы не ждать невозможного.

**AUTO влияет только на новые соединения.** Если поток уже завис, смена стратегии
его не вылечит. Плеер обычно сам переоткрывает поток — тогда применяется новая
стратегия. Иногда достаточно обновить страницу.

**Детектор удачи по входящему `inseq` не срабатывает.** Входящие TCP-данные
сознательно не перехватываются (иначе весь видеопоток шёл бы через процесс),
поэтому счётчик неудач сбрасывается по успешной отправке вверх и по окну `time`,
а не по факту получения данных от сервера. На медленном канале возможна лишняя
смена стратегии.

**Ротация QUIC не проверена.** UDP-трафик в тестах не создавался; QUIC-кандидаты
перенесены из пресетов, но подтверждения нет.

**11 пресетов из 22 не проверены.** В момент финальных тестов DPI блокировал
YouTube: соединения не устанавливались, проверять было нечем (`NO_TRAFFIC`).
Это не «сломано», а «не проверено» — нужна ручная проверка у вашего провайдера.

**Сборка не является официальным проектом** bol-van или Flowseal.

## Антивирус

WinDivert — драйвер, который перехватывает сетевые пакеты. Антивирусы справедливо
относят такие инструменты к **PUA / RiskTool / HackTool** и показывают предупреждение.
**Это ожидаемо и не означает заражения.**

**Не отключайте антивирус полностью.** Правильное действие — точечное исключение:

- добавьте в исключения папку сборки (например `C:\zapret2-easy`);
- либо конкретные файлы `bin\WinDivert.dll` и `bin\WinDivert64.sys`.

Если антивирус удалил файлы — восстановите их из архива сборки.

**Про код `0xC0000142`.** Если движок не стартует и в отчёте видно
`0xC0000142 STATUS_DLL_INIT_FAILED` — это не ошибка пресета. Так обычно ведёт
себя антивирус, который внедряет модуль в процесс и мешает инициализации
`cygwin1.dll`. Наблюдалось с Malwarebytes. Что делать: исключение на папку,
проверить `PATH` на постороннюю `cygwin1.dll`, убедиться, что не запущен второй
перехватчик (другой zapret, GoodbyeDPI, AdGuard).

## Пресеты

`general`, `ALT1`…`ALT13`, `EXP`, `FAKE-TLS-AUTO` (+3 ALT), `SIMPLE-FAKE` (+2 ALT) —
портированы из [zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube)
в синтаксис nfqws2. Плюс **AUTO** — наш пресет с автоматической сменой стратегий.

Подробности, отличия похожих пресетов и устройство AUTO — в [PRESETS.md](PRESETS.md).

Перебор пресетов — нормальная практика: у каждого провайдера свой DPI.
Меню → «5. Тесты пресетов» покажет, что открывается у каждого.

## Где логи и как удалить

`logs\zapret-easy.log` — действия меню; `logs\winws2-*.log` — отладочный лог движка
(появляется при тестах и ручном запуске с `--debug`); `logs\test-runner-*.log` —
отчёты тестов. Служба работает без `--debug`, чтобы не рос файл.

Удаление: меню → «2. Удалить». Служба останавливается и удаляется, процесс
завершается и проверяется, драйвер снимается по выбору. Затем можно удалить папку.
